AWS Tools for PowerShell - Installation

Available in AWS.Tools.Installer

Cmdlets

Name Description
Install-AWSToolsModule Installs AWS Tools for PowerShell modules from the AWS CloudFront-hosted AWS.Tools.zip and cleans up previous versions.
Update-AWSToolsModule Updates all installed AWS Tools for PowerShell modules to the latest version (or a specified version) from CloudFront.
Uninstall-AWSToolsModule Uninstalls AWS.Tools modules with comprehensive filtering options (by name, version, or preserving specific module-version pairs).
Install-AWSToolsInstaller Installs the AWS.Tools.Installer module itself from the AWS CloudFront-hosted AWS.Tools.Installer.zip.
Uninstall-AWSToolsInstaller Uninstalls the AWS.Tools.Installer module by version or by preserving a single version.
Install-AWSToolsModuleV1 Legacy compatibility. Installs AWS.Tools modules from PowerShell Gallery, replicating AWS.Tools.Installer 1.0.3 behavior.
Update-AWSToolsModuleV1 Legacy compatibility. Updates installed AWS.Tools modules from PowerShell Gallery, replicating AWS.Tools.Installer 1.0.3 behavior.
Uninstall-AWSToolsModuleV1 Legacy compatibility. Uninstalls AWS.Tools modules using Uninstall-Module, replicating AWS.Tools.Installer 1.0.3 behavior.
