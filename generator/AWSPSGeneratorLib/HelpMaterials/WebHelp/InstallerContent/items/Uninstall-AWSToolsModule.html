Uninstall-AWSToolsModule Cmdlet

Available in AWS.Tools.Installer

Synopsis

Uninstalls AWS.Tools modules with comprehensive filtering options.

Syntax

Uninstall-AWSToolsModule
-Name <String[]>
-Version <String>
-CleanUpLegacyScope <String>
-Scope <String>
-Path <String>
-Prerelease <SwitchParameter>
-WhatIf <SwitchParameter>
-Confirm <SwitchParameter>
Uninstall-AWSToolsModule
-Name <String[]>
-ExceptVersion <String>
-CleanUpLegacyScope <String>
-Scope <String>
-Path <String>
-Prerelease <SwitchParameter>
-WhatIf <SwitchParameter>
-Confirm <SwitchParameter>
Uninstall-AWSToolsModule
-Name <String[]>
-ExceptModules <Hashtable[]>
-CleanUpLegacyScope <String>
-Scope <String>
-Path <String>
-WhatIf <SwitchParameter>
-Confirm <SwitchParameter>

Description

This cmdlet removes AWS.Tools modules by deleting their directories from the file system. This approach is significantly faster than using Uninstall-Module. The function supports filtering by module name and version. AWS.Tools.Installer is excluded and must be managed using Uninstall-AWSToolsInstaller.

Parameters

-Name <String[]>
Specifies names of the AWS.Tools modules to uninstall. All AWS.Tools modules are uninstalled by default. The names can be listed either with or without the "AWS.Tools." prefix (i.e. "AWS.Tools.Common" or simply "Common").

When this parameter is specified, you will be prompted to confirm the uninstallation of each individual module, allowing for more granular control over which modules are removed.

Note: AWS.Tools.Installer cannot be specified here. Use Uninstall-AWSToolsInstaller to manage the installer module.
Aliases ModuleName
Required? False
Position? Named
Accept pipeline input? False
-Version <String>
Specifies exact version number of the module to uninstall. Wildcard versions are not supported.
Required? False
Position? Named
Accept pipeline input? False
-ExceptVersion <String>
Specifies that you want to uninstall all of the other available versions of AWS Tools except this one.

This parameter is deprecated in favor of ExceptModules. It will be removed in a future major version.
Required? False
Position? Named
Accept pipeline input? False
-ExceptModules <Hashtable[]>
Specifies an array of hashtables containing module names and versions to exclude from uninstallation. Each hashtable must contain 'Name' and 'Version' keys. This parameter provides more granular control over which specific module versions to preserve during cleanup operations.

Example: @{ Name = 'AWS.Tools.Common'; Version = '5.0.8' }
Required? False
Position? Named
Accept pipeline input? False
-CleanUpLegacyScope <String>
Runs a separate cleanup of all instances of AWSPowerShell and AWSPowerShell.NetCore found in the specified scope. The acceptable values for this parameter are AllUsers and CurrentUser.
Required? False
Position? Named
Accept pipeline input? False
-Scope <String>
Specifies the installation scope to target for uninstallation. The acceptable values for this parameter are AllUsers and CurrentUser. The AllUsers scope targets modules in a location that is accessible to all users of the computer. The CurrentUser targets modules in a location that is accessible only to the current user of the computer. Default value is 'CurrentUser'. Ignored if Path parameter is specified.
Required? False
Position? Named
Accept pipeline input? False
-Path <String>
Specifies a custom path where AWS Tools modules are installed. When specified, modules will be uninstalled from this location instead of the standard scope-based paths. This is useful for testing scenarios or custom installation locations.
Required? False
Position? Named
Accept pipeline input? False
-Prerelease <SwitchParameter>
Indicates that the version specified in the Version or ExceptVersion parameter includes a prerelease tag (e.g., 5.0.0-preview001).

Notes

This cmdlet uses Remove-ModuleItem to delete module directories for improved performance and consistent error handling.

Examples

Example 1

Uninstall-AWSToolsModule -ExceptVersion 4.0.0.0 -Confirm:$false
This example uninstalls all versions of all AWS.Tools modules except for version 4.0.0.0.

Example 2

Uninstall-AWSToolsModule -ExceptModules @(
    @{ Name = 'AWS.Tools.Common'; Version = '5.0.8' }
    @{ Name = 'AWS.Tools.S3'; Version = '5.0.8' }
) -Confirm:$false
This example provides granular control over cleanup, preserving specific versions of AWS.Tools.Common and AWS.Tools.S3 while uninstalling all other modules.

Example 3

Uninstall-AWSToolsModule -Version 4.1.754 -Confirm:$false
This example uninstalls only version 4.1.754 of all AWS.Tools modules.

Example 4

Uninstall-AWSToolsModule -Name EC2,S3 -Confirm:$false
This example uninstalls all versions of only the EC2 and S3 modules, with individual confirmation prompts for each module.

Example 5

Uninstall-AWSToolsModule -CleanUpLegacyScope CurrentUser -Confirm:$false
This example uninstalls all AWS.Tools modules and also removes legacy AWSPowerShell modules from the current user's scope.

Example 6

Uninstall-AWSToolsModule -Scope AllUsers -Confirm:$false
This example uninstalls AWS.Tools modules from the system-wide installation location.

Example 7

Uninstall-AWSToolsModule -Path "C:\CustomModules" -Confirm:$false
This example uninstalls AWS.Tools modules from a custom installation path.

Example 8

Uninstall-AWSToolsModule -WhatIf
This example performs a what-if analysis to preview what modules would be removed without making changes.

Example 9

Uninstall-AWSToolsModule -Scope AllUsers
This example removes AWS.Tools modules from the system-wide location with explicit confirmation prompts.
